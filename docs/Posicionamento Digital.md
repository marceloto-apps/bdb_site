## 1. Identidade e Posicionamento

### 1.1 Quem é a Big Data Bet

A Big Data Bet é um projeto brasileiro criado por **Luciano Zeidler**, analista de dados aplicado ao mercado esportivo. O projeto nasceu da prática — planilhas compartilhadas em um grupo no Telegram — e evoluiu para uma comunidade educacional com presença no YouTube, Instagram e Telegram.

**Não é casa de apostas. Não é canal de tips. Não é guru de aposta.**

É uma plataforma de **educação e ferramentas** para quem quer abordar o mercado esportivo com método, estatística e ciência de dados.

### 1.2 Proposta de valor central

> "Ensino as pessoas a criarem e validarem métodos para apostas esportivas usando estatística e ciência de dados."
— Luciano Zeidler
> 

**Tradução para o site:**

> Pare de apostar no escuro. Aqui você aprende a criar seu próprio método, validar com dados reais e operar com confiança no mercado esportivo.
> 

### 1.3 Diferencial competitivo

| O mercado faz | A Big Data Bet faz |
| --- | --- |
| Vende tips e palpites prontos | Ensina a construir e validar métodos próprios |
| Promete lucro fácil e rápido | Mostra o processo real, incluindo quando não funciona |
| Cobra por informação superficial | Oferece bases de dados, planilhas e backtest com profundidade |
| Cria dependência do tipster | Busca autonomia do apostador como analista |
| Usa linguagem de marketing agressivo | Comunica com tom técnico, didático e transparente |

### 1.4 Público-alvo (personas)

| Persona | Perfil | Dor principal | O que busca na BDB |
| --- | --- | --- | --- |
| **Iniciante curioso** | Aposta por hobby, já perdeu dinheiro seguindo tips, quer entender "por que perde" | Não sabe por onde começar a estudar de verdade | Fundamentos, conceitos de EV, gestão de banca, primeiros passos com dados |
| **Punter intermediário** | Já faz análise pré-jogo, conhece alguns mercados, mas opera no feeling | Falta ferramenta e base de dados para dar profundidade à análise | Planilhas, dashboards, bases históricas, filtros por liga/mercado |
| **Analista / trader avançado** | Opera com método, busca otimização e validação estatística | Precisa de backtest robusto e dados mais profundos | Backtest interativo, modelos estatísticos, Poisson avançado, automações |

### 1.5 Tom de voz e linguagem

**Referência:** o próprio Luciano nos vídeos do YouTube e mensagens no Telegram.

| Aspecto | Diretriz |
| --- | --- |
| **Registro** | Informal-técnico. Fala como um professor que também opera. "Tamo junto", "bora lá", "se ferrou" são naturais. |
| **Nível técnico** | Usa termos do mercado sem medo (punter, EV, edge, Poisson, dispersão), mas sempre explica na primeira ocorrência. |
| **Promessas** | **Jamais** prometer lucro, resultado garantido ou fórmula mágica. O posicionamento é sobre **processo e método**. |
| **Honestidade** | Mostrar quando um método **não funciona** no backtest é tão importante quanto mostrar quando funciona. |
| **Pessoa** | Tratar por "você". Português do Brasil, sem formalidade excessiva. |
| **Formatação** | Frases curtas. Parágrafos curtos. Listas sempre que possível. Dados concretos > adjetivos vagos. |

**Expressões a evitar:**

- "Lucre agora", "método infalível", "resultado garantido"
- "Não sou especialista / isso não é conselho financeiro" (a BDB **é** a referência; não se desautorize)
- Linguagem genérica de template traduzido ("mergulhe no dinâmico mundo", "explore o poder", "percepções sem precedentes")

**Expressões bem-vindas:**

- "Validado por dados", "teste antes de arriscar", "método > sorte"
- "Os números mostram que...", "no backtest de X jogos..."
- "Trabalhe com previsibilidade", "ganho de informação", "vantagem estatística"

### Bloco 3 — Manifesto (o que acreditamos)

> **Título:** No que acreditamos
> 

**6 princípios — cada um com título em negrito + uma frase de expansão:**

1. **Dados sobre opinião.** Toda decisão começa com números. Palpite é ponto de partida, nunca conclusão.
2. **Método sobre sorte.** Uma green isolada não significa nada. Consistência vem de processo validado em centenas de jogos.
3. **Transparência sobre promessa.** Mostramos o backtest inteiro — inclusive quando o método não funciona. Se o número é ruim, ele aparece.
4. **Autonomia sobre dependência.** O objetivo não é que você siga nossos tips. É que você construa, valide e confie no seu próprio método.
5. **Comunidade sobre solidão.** Apostador isolado repete erros. Aqui, todo mundo troca, questiona e evolui junto.
6. **Profundidade sobre superficialidade.** Médias ponderadas, dispersão, tendências, Poisson. Os dados que realmente importam, não a tabela de classificação.

## 6. Regras absolutas (para qualquer agente ou criador de conteúdo)

1. **Nunca prometer lucro, resultado garantido ou método infalível.**
2. **Nunca usar linguagem de template genérico** ("mergulhe no dinâmico mundo", "percepções sem precedentes"). Ser direto e específico.
3. **Sempre incluir dados concretos** quando fizer uma afirmação sobre método ou estratégia.
4. **Nunca recomendar uma casa de apostas específica** como parceira/afiliada (a menos que o Luciano instrua explicitamente o contrário).
5. **Sempre diferenciar a BDB de canais de tips.** O posicionamento é educação + ferramenta, não palpite.
6. **Manter coerência com o tom do Luciano** — técnico, acessível, honesto, sem arrogância.
7. **Todo conteúdo em português do Brasil**, tratamento por "você".
8. **Na dúvida, perguntar ao Luciano antes de publicar** — especialmente em temas que envolvam números de resultado, histórico pessoal ou posicionamento sobre casas de apostas.
